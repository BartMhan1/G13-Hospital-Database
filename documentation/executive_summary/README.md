# Executive Summary

## Project Overview

A high-level summary of the **G13 Hospital Database System** project.

## Objectives

1.  **Centralized Data Management**: Secure storage of patient health, doctor scheduling, and billing records.
2.  **Referential Integrity & Constraints**: Minimizing data entry anomalies.
3.  **Role-Based Security**: Ensuring sensitive medical history is only accessible by authorized roles.
4.  **Operational Metrics**: Pre-configured queries to analyze hospital efficiency, department revenue, and workloads.

## Key Features

*   Comprehensive patient profiling.
*   Appointment scheduling and workload balance.
*   Detailed billing tracking and outstanding balances logs.
*   Auditing capabilities through trigger executions.
